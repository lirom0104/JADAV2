# Independent source audit of IR kernel v1

Core implementation files match the frozen run2 copies. No change to the running experiment.

- All parent geometry/opacity and the base infrared loss are detached from the kernel fit. The base optimization, adaptive weights and CMO use baseIR. No direct RGB/shared-parameter gradient path exists from the new fit.
- New raw kernels and optimizer moments participate in capture/restore, PLY and module metadata, clone/split/prune and EMA. Seven focused lifecycle tests passed.
- Training-log PSNR uses inherited per-channel averaging; official metrics.py correctly uses whole-image MSE. CPU smoke-image recomputation explains the discrepancy. See smoke_v1/metric_shape_diagnostic.json.
- Existing full train checkpoint omits RNG, residual camera queue and exportEMA. Parameter/Adam continuation works but interrupted training is not numerically equivalent to uninterrupted training. Current formal models are uninterrupted, from dataset initialization, and the runner has no checkpoint-resume route. If recovery becomes necessary, preserve protocol and record the distinction explicitly; do not claim equivalent resumed trajectory without implementing and verifying saved runtime state.
- Full scene quality gain remains unproven. Once first scene completes, same-model kernel enabled/disabled all-view ablation should isolate representation effect from variation in base training. It is auxiliary; official fixed-baseline comparison governs acceptance.
